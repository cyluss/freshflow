확정 사양이 종료 기준을 만족한다. 경제 탐색을 종료하고 동결한다.

## 4. 계약 신호별 성과 (과거 · 계약이 아무 날이나 가능하던 시절)

| 신호 | 판수 | 발생 빈도 | 평균 | 양수비율 |
|---|---|---|---|---|
| 전체 | 1,000 | 100% | 37 | 43.5% |
| 못판 25% 이상 | 305 | 30.5% | 427 | 50.8% |
| 못판 40% 이상 | 111 | 11.1% | 837 | 62.2% |
| 못판 40% + 재고 0.5t 미만 | 106 | 10.6% | 781 | 60.4% |

신호가 강해질수록 43.5 → 50.8 → 62.2% 로 오른다.
V0 입고 증설은 어떤 관측으로도 41% 를 넘지 못했다. 그 점이 질적 차이다.

강한 신호는 발생 빈도가 11% 다. 기다릴수록 정확하지만 기회는 준다.
이 trade-off 를 플레이어 판단의 재료로 둔다.

## 부록. 계약 타이밍 탐색과 폐기

계약을 언제 사느냐가 선택인지 확인하려고 두 안을 측정했다.

| 안 | 가격 |
|---|---|
| A 고정 | 항상 1,750 |
| B 기간비례 | 1,750 × 남은기간 / 30 |
| C 고정비+비례 | fixed + (1,750-fixed) × 남은기간 / 30 |

### A 에서의 계약일 (1,000시드)

| 계약일 | 평균 | 승률 |
|---|---|---|
| 1일 | 613 | 54.0% |
| 6일 | 37 | 43.5% |
| 15일 | -688 | 28.7% |
| 20일 | -1,050 | 18.0% |

단조감소다. 최적일이 1일인 판이 62.1% 이고
계약이 이득인 판의 96.1% 에서 Day1 도 이득이다.

### B 결과

Day1 최적이 16.3% 로 내려갔으나 Day20+ 가 43.8% 로 몰렸다.
가격이 남은 기간에 정확히 비례하면 기다림의 대가가 사라져 후반이 지배한다.

### C 스윕 (fixed 0 ~ 1,750)

| fixed | Day1 최적 | Day5~19 | Day20+ |
|---|---|---|---|
| 0 | 16.3% | 24.8% | 43.8% |
| 600 | 21.5% | 24.3% | 36.0% |
| 900 | 22.5% | 24.3% | 33.5% |
| 1,200 | 24.8% | 24.0% | 30.5% |
| 1,750 | 58.0% | 18.5% | 17.3% |

중간 구간이 fixed 와 무관하게 24% 로 고정된다. fixed 로는 중간을 키울 수 없다.

### 착시 확인

fixed 1,200 에서 Day20+ 최적 판을 분해했다.

| 최적 구간 | 판수 | 최적 가치 평균 | 양수 비율 |
|---|---|---|---|
| Day1~4 | 182 | 1,849 | 73.1% |
| Day5~19 | 96 | 1,154 | 67.7% |
| Day20+ | 122 | -760 | 19.7% |

후반 최적의 80% 가 음수다. 늦게 사는 전략이 아니라
사지 말아야 할 판에서 손실을 줄이는 행동이다.

### 신호 전략 재측정

커널 상태에 최근 사흘 관측을 실어 화면과 같은 값만 쓰는 전략을 만들었다.

| fixed | 계약1일 | 신호 25%/3t | 신호 40%/3t |
|---|---|---|---|
| 0 | 500 (50.0%) | 528 (42.8%) | 334 (30.5%) |
| 1,200 | 500 (50.0%) | 275 (37.5%) | 87 (23.8%) |
| 1,750 | 500 (50.0%) | 159 (35.8%) | -25 (23.0%) |

어느 지점에서도 신호 대기가 고정 Day1 을 승률로 이기지 못한다.

### 결론

기간비례를 폐기한다. 이 판단은 지금도 유효하다.

다만 고정 1,750 이라는 결과는 부록 2 에서 노출량 선택으로 대체되었다.
현재 계약은 사느냐 마느냐가 아니라 얼마나 받을 것인가다.
계약과 판매의 판단 종류가 다른 것은 결함이 아니라 역할 분리다.

```
계약    사느냐 마느냐. 사려면 초반
판매    언제 사느냐. 재고 신호
```

측정 과정에서 커널 상태에 `recent` 를 추가했다.
전략과 화면이 같은 관측을 읽게 하는 장치이므로 남긴다.

## 부록 2. 계약을 노출량 선택으로 확장

이진 계약을 네 선택지로 바꿨다. 질문이 바뀌었다.

```
이전   이번 달 추가 공급에 노출될 것인가
지금   이번 달 추가 공급에 얼마나 노출될 것인가
```

### 확정 사양

| X | 가격 | 성격 |
|---|---|---|
| 0t | 0 | 노출 회피 |
| 0.5t | 875 | 보수적 노출 |
| 1t | 1,625 | 중간 노출 |
| 1.5t | 2,250 | 공격적 노출 |

첫날 1회 선택, 이후 변경 불가, 유지비 없음.
추가 0.5t 가격이 875 / 750 / 625 로 완만히 체감한다.

### 가격곡선 탐색

세 안을 400시드로 재고 중간안을 골랐다.

| 안 | 1.5t 평균 | 최선 0 / 0.5 / 1 / 1.5 | 침체 1.5t |
|---|---|---|---|
| 선형 875/t | 79 | 42.8 / 14.2 / 20.5 / 22.5 | 7.1% |
| 중간 (채택) | 379 | 42.0 / 10.8 / 19.5 / 27.8 | 9.5% |
| 강한 할인 | 659 | 40.0 / 9.3 / 16.0 / 34.8 | 19.0% |

선형은 1.5t 기대가치가 거의 0 이고 강한 할인은 침체에서도 큰 노출이 나쁘지 않게 되어
전망과 노출량의 정렬이 무너진다. 중간안이 둘을 피한다.

### 1,000시드 검증

| X | 가격 | 평균 | 승률 | 판매 결합 | 결합 승률 |
|---|---|---|---|---|---|
| 0t | 0 | 0 | - | 347 | 40.2% |
| 0.5t | 875 | 525 | 59.1% | 1,163 | 73.5% |
| 1t | 1,625 | 713 | 55.8% | 1,659 | 73.2% |
| 1.5t | 2,250 | 537 | 50.0% | 1,799 | 69.1% |

| 최선 X | 계약만 | 판매 결합 |
|---|---|---|
| 0t | 39.7% | 29.8% |
| 0.5t | 10.9% | 9.1% |
| 1t | 18.3% | 15.1% |
| 1.5t | 31.1% | 46.0% |

### 시작 수요와 노출량

| 국면 | 판수 | 0t | 0.5t | 1t | 1.5t |
|---|---|---|---|---|---|
| 침체 | 107 | 60.7% | 6.5% | 20.6% | 12.1% |
| 정상 | 790 | 38.9% | 11.0% | 18.0% | 32.2% |
| 호황 | 103 | 24.3% | 14.6% | 18.4% | 42.7% |

단조 정렬이면서 결정론적이지 않다. 호황에서도 노출 회피가 24.3% 다.

### 판정

| 조건 | 결과 |
|---|---|
| 네 옵션 모두 생존 | 통과 |
| 시작 수요와 노출량 정렬 | 통과 |
| 1.5t 단독 지배 없음 | 31.1% |
| 0.5t 가 안전한 선택으로 존재 | 승률 59.1% 로 최고 |
| 판매 결합에서 1.5t 과반 미만 | 46.0% |
| 결합 승률이 X 와 함께 오르지 않음 | 73.5 → 73.2 → 69.1% |

1.5t 와 판매의 결합이 46.0% 로 경계다. 다만 결합 승률이 69.1% 로 가장 낮다.
자주 최고 수익을 내지만 실패 위험도 큰 공격적 빌드라는 성격이 남는다.

### 남은 확인

밸런스가 아니라 플레이테스트 항목이다.

- 플레이어가 0.5t 와 1t 를 서로 다른 선택으로 느끼는가
- 1.5t 와 판매의 조합이 명백한 정답 빌드로 보이지 않는가

## 부록 3. 월간 성향 도입

### 문제

플레이 중 전망이 매번 평년으로 보였다. 10,000시드로 확인했다.

| 항목 | 값 |
|---|---|
| 세 구간 모두 평년 | 79.7% |
| similar 판정 | 86.4% |
| high / low 판정 | 0% |
| 전망 조합 가짓수 | 3 |

마르코프가 스무 날이면 정상분포로 수렴하므로 하순은 어떤 시드든 평년이었다.
blur 의 노이즈 0.35 가 확률을 더 평탄하게 만들었다.

### 규칙

판 시작에 생산과 수요의 월간 성향을 각각 뽑는다. 30일 내내 유지된다.

```
tiltP  [0.25, 0.5, 0.25]   침체 / 평년 / 호황
tilt   0.5                 기울기 세기
```

성향별 전이행렬은 서로 거울상이다. 정상분포 자체가 기운다.

| 성향 | 정상분포 |
|---|---|
| 침체 | 54.5 / 36.4 / 9.1% |
| 평년 | 25.0 / 50.0 / 25.0% |
| 호황 | 9.1 / 36.4 / 54.5% |

### 전망 다양성 (10,000시드)

| 판정 | 이전 | 지금 |
|---|---|---|
| similar | 86.4% | 43.2% |
| mostlyHigh | 6.8% | 27.3% |
| mostlyLow | 6.8% | 26.9% |
| high | 0% | 1.3% |
| low | 0% | 1.2% |

세 구간 모두 평년이 79.7% 에서 39.9% 로 내려갔다.

### 성향과 실제 세계 (3,000시드)

| 수요 성향 | 판수 | 침체일 | 호황일 | 평균 수요 |
|---|---|---|---|---|
| 침체 | 24.9% | 49.0% | 9.6% | 16.3t |
| 평년 | 51.9% | 23.7% | 24.1% | 20.5t |
| 호황 | 23.2% | 9.6% | 49.3% | 25.0t |

성향 vs 평균 수요 r=0.61, 성향 vs 평균 생산 r=0.59.

### 계약 X 재검증 (800시드, 가격 불변)

| X | 평균 | 승률 | 최선 | 판매 결합 최선 |
|---|---|---|---|---|
| 0t | 0 | - | 43.5% | 36.0% |
| 0.5t | 618 | 55.4% | 11.4% | 8.6% |
| 1t | 874 | 50.4% | 16.5% | 13.1% |
| 1.5t | 625 | 47.0% | 28.6% | 42.3% |

| 수요 성향 | 0t | 0.5t | 1t | 1.5t |
|---|---|---|---|---|
| 침체 | 66.3% | 9.1% | 11.8% | 12.8% |
| 평년 | 45.9% | 12.4% | 14.4% | 27.3% |
| 호황 | 17.7% | 11.3% | 25.1% | 45.8% |

기울기가 이전보다 선명하고 조합 쏠림은 46.0% 에서 42.3% 로 줄었다.
가격은 손대지 않았다.

### 결정성

월간 성향도 같은 시드 RNG 에서 뽑는다. 회귀조건으로 못 박았다.

```
같은 시드 → 같은 성향 → 같은 일별 국면 → 같은 생산·수요 → 같은 결과
```

골든 216판은 세계가 바뀌었으므로 전면 갱신했고 성향을 기록 항목에 추가했다.
