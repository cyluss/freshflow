# V0 동결과 V1 설계

## 결론

V0 경제는 v2 로 동결한다.
후보 B 초과물량 계약을 탐색 후보에서 구현 후보로 승격한다.
구매 신호는 상류 생산 전망이 아니라 하류 흡수력이다.

## V0 동결 기준선

| 항목 | 값 |
|---|---|
| 초기 한도 | 집하 20t · 창고 30t · 판매 21t |
| 증설 단위 | 집하 +2 · 판매 +1 |
| 증설 가격 | 1,125원 / 309원 |
| 유지비 | 26 / 8 / 33 |
| 생산 | 평균 14/20/27 · 분산 2.5 |
| 수요 | 평균 10/20/32 · 분산 3 |
| 기간 | 30일 |

## upstream 투자의 설계 조건

E1 의 결과로 조건을 넷으로 확장한다.

| 조건 | 의미 |
|---|---|
| 상태 의존성 | 특정 상황에서만 가치가 커진다 |
| 사전 관측성 | 그 상황을 구매 전에 플레이어가 볼 수 있다 |
| 충분한 분산 | 판마다 투자 가치가 손익분기점을 넘나든다 |
| 가치 정렬 | payoff 가 실제 이익과 같은 방향으로 움직인다 |

네 번째가 E1 에서 추가되었다. B 는 초과생산에 payoff 를 걸었으나
초과생산이 많은 판은 수요가 약해 받아도 손해였다. 상관이 -0.16 이었다.

## B 초과물량 계약

### 규칙

생산이 기존 집하 한도를 넘는 날에만 최대 X t 를 추가로 받는다.
목표재고와 창고 제약은 그대로 적용한다. 일일 유지비는 없다.

```
baseAcc = min(prod, cap, need)
take    = min(prod - cap, X, 남은 need, 창고 여유)
```

### 측정값 (X=2t · 가격 750 · 6일 구매)

| 항목 | 값 |
|---|---|
| 평균 | -55 |
| 승률 | 42% |
| 표준편차 | 2,988 |
| p10 / p50 / p90 | -3,127 / -664 / 4,025 |
| 발동일 | 9.4일 |
| 추가 매입 | 12.9t |

승률이 중간 영역이고 편차가 평균보다 크다. 가치 분산 조건을 통과한다.
매입단가 후보가 0% 또는 100% 로 붙었던 것과 대조된다.

## E3a. 못 판 수요 × 현재 재고

시드 2,000. 양수비율과 건수다.

| | 못판 <10% | 10~25% | 25~40% | 40~55% | 55%+ |
|---|---|---|---|---|---|
| 재고 ~0.5t | 41% (127) | 44% (208) | 47% (316) | 53% (170) | 63% (30) |
| 0.5~3t | 33% (133) | 43% (65) | 54% (37) | - | - |
| 3t+ | 27% (761) | 33% (116) | 47% (30) | - | - |

재고는 독립적인 정보를 준다. 낮은 못판 구간에서 재고로 14%p 가 갈린다.
방향도 가설대로 재고가 적을수록 좋다.

## B 의 정보 한계

| 신호 | 양수비율 | 발생 빈도 |
|---|---|---|
| 못판 25% 이상 | 51% | 30% |
| 못판 40% 이상 + 재고 0.5t 미만 | 55% | 10% |
| 참고) 판매 증설 재고 8t | 59% | 상시 |

**B 는 강한 신호를 찾은 것이 아니라 V1 최소 기준을 충족했다.**

신호가 강해질수록 양수비율이 29 → 39 → 51 → 55% 로 오른다.
V0 집하에서는 어떤 관측 조합으로도 41% 를 넘지 못했다. 그 점이 질적 차이다.

명확한 trade-off 가 있다. 확실한 신호를 기다릴수록 구매 기회가 희귀해진다.
플레이어가 확실한 신호를 기다릴지 약한 신호에서 먼저 베팅할지 고를 여지가 된다.

## 인과 구조 정정

기존 문서의 다음 가설은 E1~E3 가 반증했다.

```
(폐기) 풍작 전망 → 풍작에 payoff 가 발생하는 계약의 가치 증가
```

실제 인과는 이렇다.

```
최근 못 판 수요 + 낮은 재고
        ↓
하류 흡수력 신호
        ↓
추가 물량의 가치
        ↓
초과물량 계약 구매
```

생산은 구매 신호가 아니다. 계약이 실제로 돈을 만들기 위한 두 번째 조건이다.

```
하류 흡수력 AND 향후 초과생산 → B payoff
```

## 설계 원칙

> 투자 신호는 그 설비가 처리하는 입력이 아니라
> 추가 산출물을 받아줄 다음 단계에서 나올 수도 있다.

직렬 공급망에서 상류 설비의 가치는 상류 사건이 아니라 하류 흡수력이 정한다.
V1 에서 새 투자를 설계할 때 이 방향으로 먼저 신호를 찾는다.

## 탐색 종료 선언

E3b 생산 전망 추가는 하지 않는다. E1 에서 상관이 -0.03 이었고
E3a 의 상위 칸이 30건뿐이라 추가 분해는 표본을 잘라 우연한 셀을 찾을 위험이 크다.

기존 구조의 파라미터 축은 전수 검사했다.

| 축 | 결과 |
|---|---|
| 가격 35~100% | 판매 승률 34% 고정 |
| 유지비 1~3배 | 셋 다 함께 오르내림 |
| 예보 gap | 판매에서 부호 반대 |
| 초기 집하 한도 18~20 | 집하 살리면 판매 죽음 |
| 창고 21~30 | 둘 다 죽음, 무투자 최선 53% |
